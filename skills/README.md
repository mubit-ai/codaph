# Skills

This directory contains repo-shared agent skills that contributors can reference directly from prompts.

To use a skill, include a markdown link to its `SKILL.md` file in the prompt. For example:

```md
[$codaph-observability](/Users/shankha/code/codaph/skills/codaph-observability/SKILL.md)
```

Current skills:

- `codaph-observability`: standard Codaph workflow for context loading, checkpoints, diagnostics, reflection, and handoffs.
